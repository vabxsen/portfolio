# Portfolio functional audit — 23 September 2026

## Scope and deployment status

Reviewed the current source, including the existing Claude animation changes, and the live site at https://vabxsen.vercel.app/. Public live checks were read-only. Admin mutations ran against a disposable local copy with synthetic credentials and local storage; no production content was edited.

This report records local verification of the fixes below. Production deployment must be verified separately after publishing.

## Issues fixed

| Area | Problem | Result |
| --- | --- | --- |
| Project order | Project-detail Move up/down changed the underlying array but left featured order unchanged. | Both sets of controls reorder within the project's visible group, with correct boundary states. |
| Screenshot selection | Selecting the default preview removed the original built-in screenshot from the choices. | Original project images remain selectable. The default option is labeled accurately. |
| Add project | Optional URLs/images could inherit empty strings that failed validation. | New projects initialize those fields to null and can save without optional links. |
| Draft preview | Preview could show an older saved draft while edits were pending. | Preview saves pending edits privately, then opens that draft. Save failures leave edits intact. |
| Backup export | The Blob URL was revoked immediately after clicking download. | The browser has time to consume the download before the URL is released. |
| Publishing recovery | After a partial publish failure, reloading could falsely say the site was up to date and disable retrying. | Admin status reads the public record's version and keeps publishing available until it matches. |
| Optional GitHub profile | Clearing GitHub could leave GitHub-labeled links pointing to disabled/missing sections. | Those optional links are omitted when no GitHub URL is set. Repository query parameters are merged correctly. |
| New-project preview | Projects without a recognized slug or screenshot displayed Native AI's mockup. | The fallback uses the new project's own name, description, category, and technologies. |
| Login failures | An HTML gateway error produced a JSON-parser message. | Login displays a readable retry message and re-enables the form. |
| Image uploads | A JPEG header without valid image pixels could be accepted. | Uploads are decoded and validated before storage, with a 24-megapixel limit. Sanitized original bytes are preserved without recompression. |

Also added descriptive names to array Add controls, more readable validation errors, and a synchronous guard against duplicate editor operations.

## Boundaries

Browser interaction testing used Chromium with desktop and mobile viewport emulation, including reduced-motion checks. It does not establish identical behavior on every physical device or browser. Third-party project applications were checked as link destinations; their internal features are separate applications and were not audited. Real production admin writes and Vercel Blob failure injection were intentionally not exercised; local tests covered the same app workflows and simulated partial publication records.
